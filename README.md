## <a name="introduction">🤖 Introduction</a>

This project focuses on building a fully functional clone of Jira, a popular project management platform, using a modern web development stack. It covers implementing various features expected from such a platform, including detailed task management views and project organization within workspaces.




## <a name="tech-stack">⚙️ Tech Stack</a>

- Next.js
- TypeScript
- Hono.js 
- Appwrite
- Radix UI
- Tailwind CSS

## <a name="features">🔋 Features</a>

👉 **Project Management**: Implements core project entity structures within workspaces, allowing users to organize and manage projects effectively. Includes features for loading projects with validation for user access and permissions.

👉 **Comprehensive Task Management**:
-  Provides a "My Tasks" page with multiple views:
- Table view for structured task lists.
-  Kanban board view with drag-and-drop functionality for task status updates.
- Calendar view for tracking deadlines.

👉 **Individual Task Details**: Includes dedicated pages for viewing and editing individual task details.

👉 **API Endpoints**: Creates necessary API endpoints for handling project and task-related data and operations.

👉 **UI Components & Settings**: Develops UI elements like project avatars, forms for project/task creation/management, and dedicated pages for individual project settings.

👉 **Analytics**: Includes analytics features to track task progress.

👉 **User Experience**: Incorporates UX improvements such as query invalidation upon logout and functionality for workspace creation.

and many more, including code architecture and reusability.
